# MeaMart Platform Guide

This guide covers the most important steps for using the platform.

- Prepare the title, description, and photos.
- Choose the correct category.
- Accurately complete the required fields.

- Review performance from the Seller Dashboard.
- Update price or description as needed.
- Delete or edit inactive ads.
