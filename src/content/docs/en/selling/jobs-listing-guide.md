# Jobs Listing Guide

Attract the right talent by being clear about the job requirements.

## Job Details
- **Title:** Be specific (e.g., "Senior Web Developer", not just "Developer").
- **Requirements:** List the required skills and experience.
- **Location:** Mention if it's on-site, remote, or hybrid.
- **Salary:** (Optional but highly recommended) Mention the salary range.

## Application Process
- Clearly state how candidates should apply (e.g., via WhatsApp, email, or a link).
